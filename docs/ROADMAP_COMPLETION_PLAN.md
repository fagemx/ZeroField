# Roadmap 全項完成補強計畫

依據 `PRODUCTIZATION_ROADMAP.md` 的原始條目驗收；前次核心整合版不能代表下列缺口已完成。

## Task 1：完整 DAG 量產與匯流

補齊一次拆鏡 → 讀取新增分鏡列動態展開 → 每列生圖／影片（可平行音訊）→ 全列完成後僅合成一次。節點提供明確一次／逐列／匯總範圍與資料來源；保留既有 per-row 定義相容。審核未完成不能展開下游；零列、失敗、取消、重試不得死結或重複展開。輸入保留穩定 row ID，依表格順序聚合；選取單列與狀態篩選可由指定節點開始重跑。真正的跨頁 doc 輸出應支援文字提案。加入 PostgreSQL 整合測試，更新 EXECUTION_API 文件。

## Task 2：可執行 Worker 與完整產線範本

新增可配置 worker runtime，支援 OpenAI-compatible LLM、ComfyUI 工作流、HTTP 多模態 bridge、FFmpeg 合成；安全存取專案資產、租約續期、逾時、錯誤回報、無 prompt shell 執行。使用真實 FFmpeg 及隔離 HTTP fixture 驗證。四種專案範本自動帶入可儲存的真實圖與輸入／輸出／型態，LLM 拆鏡明確結構格式。外部供應商模型與授權仍由部署者設定。

## Task 3：表格媒體與批次操作完整 UI

單格重抽、影片秒數及解析度、音訊長度、裸 asset URL 類型辨識、狀態篩選與整批勾選。Flow UI 支援新 scope、row source、指定起點與實際進度。直接在 sheet 可標註與讀取共享討論／鎖定資訊。公式輸出重算旗標，確認 M0/M4 交界的匯出不會靜默丟失資料。

## Task 4：驗收、審查與部署

逐項對照 M0～M7，修正發現的缺陷。執行完整 Python／前端／PostgreSQL／HTTP／真實本機媒體產線測試；build 與 clean wheel 安裝；可用時執行 Docker build／Compose smoke。更新驗收矩陣與部署文件，外部憑證／未執行的遠端 CI 不冒稱已驗證。
