使用者指出畫面過早圍繞影片製作，要求先把日常操作做順，並明確表示「先不用影片播放」。目前主路徑是：建立專案 → 放入文件或表格 → 描述工作 → 核對代理提案 → 確認寫回。文件、表格與工作流仍為共同能力；各領域範本只是起點。

## 已實作的介面調整

- 專案大廳新增搜尋與簡短操作引導；新建預設空白，行銷／美術／影劇為並列的可選範本。網址代號放在進階設定，留空可自動產生。
- 表格以閱讀為主：固定列高、文字摘要、圖片縮圖、搜尋及狀態篩選；欄位類型／增刪集中在設定面板，匯出放在更多選單。
- 雙擊或 Enter／F2 編輯儲存格，方向鍵沿可見列移動；保留 Excel 多列貼上。編輯保留原始版本，避免在資料已變更時覆蓋。未儲存時關閉／切頁會提醒。
- 列詳情集中整列內容、討論及版本紀錄。當後端把連續的內容與欄位設定合成整表變更時，列紀錄亦會列出，並清楚標示為「表格整體變更」，避免誤報無紀錄。
- 「交給代理」先顯示處理範圍並請使用者描述工作，再把可讀的列名稱與需求放入對話草稿，不直接送出或執行。過長的草稿會在此處提示縮短。
- 助理初始收起，需使用時再開啟；歡迎文字與建議提問改成通用工作需求。表格提案按鈕使用「確認寫回」，資料使用說明依專案遮罩模式顯示。
- 圖片保留預覽、替換及版本入口。影片使用附件卡與下載連結；表格、媒體面板及歷史面板皆不建立影片播放器。影片儲存與 Worker 能力仍保留。
