# SPEC 15 — 去流水線化的雙空間創作 UI 設計（保留三欄骨架，整併 6 站為「故事與世界 · 分鏡片場 ＋ 右上成片預覽」）

> **目標**：供 UI 代理先出樣板（HTML Mockup / Prototype），確認視覺與互動動線後再進實作。
> **核心原則**：
> 1. **保留原設計最棒的 3 個成果**：
>    - 保留「頂欄 ＋ **清單 · 主畫面 · 詳情** 固定三欄骨架 ＋ **劇組**收件匣 ＋ `Ctrl K` 收納工程工具」的乾淨結構；
>    - 保留深色背景配**單一琥珀強調色（唯一主要行動按鈕）**；
>    - 保留「選取跟著你走（`S03`）」與鍵盤快捷鍵（`↑↓` 換鏡 · `A` 核准 · `R` 重拍 · `G` 劇組）。
> 2. **修正原設計的 3 個「工廠流水線」問題**：
>    - ❌ **拿掉頂欄 `① 故事 → ② 角色與場景 → ③ 分鏡 → ④ 片場 → ⑤ 審片 → ⑥ 成片` 的 1～6 編號與拆站**。
>    - ✅ **頂欄中央只留 2 個不帶編號的創作空間切換**：**`故事與世界`**（合併原 ①+②）與 **`分鏡片場`**（合併原 ③+④+⑤）；把原 **`⑥ 成片`** 與右上角重複的 **`▷ PLAY`** 整併為右上角同一顆 **`[ ▷ 成片 7/8 ]`**。
>    - ✅ **把「點子 ➔ 故事」的構成式孵化（`SPEC_14`）直接放在『故事』主畫面**，不再把 AI 劇本演化藏進 `Ctrl K`。

## 1. 頂欄導覽設計（Top Bar — 從 6 站流水線改為 2 個平行創作空間）

```text
┌──────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ [ZF] The Last Signal ▾ / 第 1 集 ▾    ╭──────────────────┬───────────────────────╮   [🔍 Ctrl K] [👥 劇組 3] [▷ 成片 7/8] │
│                                       │  故事與世界 有更新 │  分鏡片場 8鏡·1缺圖·2待審 │                                        │
│                                       ╰──────────────────┴───────────────────────╯                                        │
└──────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

### 為什麼這樣改？
1. **沒有 `1 → 2 → 3 → 4 → 5 → 6` 編號**：創作者隨時在「改故事/調角色」跟「排鏡頭/看成片」之間自由切換，不像在填報單過關。
2. **「角色與場景」不再迫使人離開故事頁**：寫故事時右欄本來就列出所有出場角色、場景、道具；點任何角色（例如 `@CAST-02 還沒有圖`）直接在右欄原地展開定妝生圖與造型變體（或點「查看全部資產牆」在故事主畫面切換），不佔頂欄一站。
3. **「分鏡 · 片場 · 審片」合為同一個『分鏡片場』空間**：因為左欄都是同一組鏡頭清單 `S01..S08`、右欄都是當前鏡頭 `S03` 的詳情，把它們放在同一個空間，導演才不用為了看 `S03` 的 3D 走位與拍出來的影片在頂欄連跳三個分頁。
4. **消滅重複的成片入口**：原本頂欄有 `⑥ 成片`，右上又有 `▷ PLAY`。現在統一為右上角 **`[ ▷ 成片 7/8 ]`**（點擊直接拉開全集連播預覽與匯出 MP4，還沒拍完的那 1 鏡自動用 3D 預演片墊底連播）。
