重置镜头叙事

把镜头的画面描述 / 台词恢复到最近一次 AI 生成的原始版本，撤销后续的人工 / AI 改写。

请求参数说明

Path 参数
参数	类型	必填	说明
shotId	string	是	
对外镜头号。
示例：sh_7Qz3Rk9
响应字段说明
参数	类型	必填	说明
shotId	string	是	
对外镜头号。

description	string	否	
恢复后的画面描述。

dialogue	string	否	
恢复后的台词。

(other fields)	object	是	
其余字段同「查询镜头详情」（sceneId / shotIndex / sceneIndex / durationSeconds / selectedImageUrl / selectedVideoUrl / status）。

注意

该镜头没有可恢复的原始快照时（如老数据、或本来就是手动创建的镜头）返回 400 DRAMA_REQUEST_FAILED。
不可逆：恢复后无法再恢复到重置前的人工改写内容，请谨慎调用。

请求示例

cURL
Python
JavaScript
Java
java
复制
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/shots/sh_7Qz3Rk9/narrative-edits"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .method("DELETE", HttpRequest.BodyPublishers.noBody())
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
