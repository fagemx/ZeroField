/episodes/{episodeId}/films
复制
导出成片

把该集所有镜头视频拼接导出为一条完整成片，异步任务。

请求参数说明

Headers
参数	类型	必填	说明
Idempotency-Key	string	否	
幂等键。
Path 参数
参数	类型	必填	说明
episodeId	string	是	
对外剧集号。
示例：ep_4Rt7QxNp1
响应字段说明
参数	类型	必填	说明
taskId	string	是	
任务号。

type	string	是	
固定为 FILM_EXPORT。

result	object	否	
SUCCEEDED 后为 { fileId, videoUrl }，videoUrl 是 24 小时有效的签名地址。

注意

前置条件：该集至少有一个镜头已生成视频，否则返回 409 DRAMA_STAGE_PRECONDITION（极小概率的竞态场景会退化成 400 DRAMA_REQUEST_FAILED）。
同一集最多保留 10 条已导出（EXPORTED）记录，超出的旧记录会被自动淘汰，导出中 / 失败记录不参与淘汰计数。

复制
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/episodes/ep_4Rt7QxNp1/films"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .header("Idempotency-Key", "req-20260916-0001")
            .method("POST", HttpRequest.BodyPublishers.noBody())
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
