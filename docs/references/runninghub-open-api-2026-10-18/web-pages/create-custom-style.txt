创建自定义画风

新建一个自定义画风预设。

请求参数说明

Body 参数
参数	类型	必填	说明
label	string	是	
画风名称。
示例：赛博水彩

prompt	string	是	
画风提示词。
示例：cyberpunk watercolor style, neon rim light

coverUrl	string	是	
封面图地址（需先自行上传到可公开访问的存储，本接口不接收文件）。
响应字段说明
参数	类型	必填	说明
styleId	string	是	
对外自定义画风号。

label	string	是	
画风名称。

prompt	string	是	
画风提示词。

coverUrl	string	是	
封面图地址。

注意

新建的画风可能需要经过审核才会出现在 GET /styles/custom 里；具体审核策略以平台配置为准，本 API 不提供查审核状态的字段。

请求示例

cURL

Java
java
复制
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        String json = """
            {
              "label": "赛博水彩",
              "prompt": "cyberpunk watercolor style, neon rim light",
              "coverUrl": "https://cdn.example.com/styles/cyber-watercolor.png"
            }
            """;

        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/styles/custom"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .method("POST", HttpRequest.BodyPublishers.ofString(json))
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
