登记回调地址

登记一个接收任务终态与账单事件的回调地址。

请求参数说明

Body 参数
参数	类型	必填	说明
url	string	是	
回调地址，必须是可公网访问的 https 地址（长度不超过 2048）：非 https、带用户名密码、主机名无法解析，或指向 localhost / 内网 / 回环 / 链路本地等非公网地址，均返回 422 DRAMA_VALIDATION_FAILED。
示例：https://api.example.com/webhooks/runninghub

events	string[]	否	
订阅的事件类型；留空或传空数组表示订阅全部事件类型。仅允许上述 4 个事件，含未知事件返回 422；最多 10 项，超出同样返回 422。
可选值： task.succeededtask.failedtask.canceledbill.charged
响应字段说明
参数	类型	必填	说明
webhookId	string	是	
对外回调登记号，wh_ 前缀。

url	string	是	
回调地址。

events	string[]	是	
订阅的事件类型；空数组代表全订阅。

secret	string	是	
签名密钥，仅本次创建响应明文返回，请立即保存。64 位十六进制字符串。

status	enum	是	
状态，新建恒为 ENABLED。
可选值： ENABLEDDISABLED

createdAt	string	是	
ISO-8601 创建时间。

注意

每个企业 Key 最多登记 5 条，超出返回 400 DRAMA_REQUEST_FAILED；url 不是公网 https 地址返回 422 DRAMA_VALIDATION_FAILED（见 url 参数说明）。
每次投递前会再校验一次目标地址是否仍为公网地址（防 DNS 重绑定），解析到内网地址的投递会直接按失败处理。

import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        String json = """
            {
              "url": "https://api.example.com/webhooks/runninghub",
              "events": [
                "task.succeeded",
                "task.failed"
              ]
            }
            """;

        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/webhooks"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .method("POST", HttpRequest.BodyPublishers.ofString(json))
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
