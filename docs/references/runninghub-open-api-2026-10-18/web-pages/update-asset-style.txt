绑定资产画风

为单个资产单独指定自定义画风，覆盖项目全局画风。

请求参数说明

Path 参数
参数	类型	必填	说明
assetId	string	是	
对外资产号。
示例：as_5Ln9Vt2
Body 参数
参数	类型	必填	说明
stylePresetId	string	否	
自定义画风号（POST /styles/custom 返回的 styleId，st_ 前缀），传 null 或不传表示清除单独设置、回落项目全局画风。

注意

重要：这里的 stylePresetId 必须是「自定义画风」分组下 st_ 前缀的用户画风号，不是 GET /catalog/styles 返回的内置画风数字 id——传内置画风的数字字符串会因为前缀不匹配返回 404 DRAMA_NOT_FOUND。

请求示例

cURL
Python
JavaScript
Java
java
复制
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        String json = """
            {
              "stylePresetId": "st_2Kd7Nx9"
            }
            """;

        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/assets/as_5Ln9Vt2/style"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .method("PUT", HttpRequest.BodyPublishers.ofString(json))
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
