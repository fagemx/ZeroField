/tasks
复制
任务列表

游标分页查询当前企业 Key 下的任务，可按状态 / 类型过滤。

请求参数说明

Query 参数
参数	类型	必填	说明
status	enum	否	
按状态过滤；不在枚举内的值返回 422 DRAMA_VALIDATION_FAILED。
可选值： QUEUEDRUNNINGSUCCEEDEDFAILEDCANCELED

type	enum	否	
按任务类型过滤；不在枚举内的值返回 422 DRAMA_VALIDATION_FAILED。
可选值： ASSET_EXTRACTSTORYBOARD_GENERATESHOTS_REBUILDSHOT_IMAGE_GENERATESHOT_VIDEO_GENERATEASSET_IMAGE_GENERATEFILM_EXPORTPROJECT_IMPORTPROJECT_GENERATESCRIPT_REFINESCENE_REFINEPROJECT_REEXTRACTASSET_IMAGE_EDIT

cursor	string	否	
游标，取上一页响应的 nextCursor。

limit	integer	否	
每页条数，1~100，缺省 20，越界返回 422。
响应字段说明
参数	类型	必填	说明
items	object[]	是	
本页任务列表，元素结构同「查询任务」的 data。

nextCursor	string	否	
下一页游标；为空表示没有下一页。

Java
java
复制
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/tasks?status=%3Cstatus%3E&type=%3Ctype%3E&cursor=%3Ccursor%3E&limit=%3Climit%3E"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .method("GET", HttpRequest.BodyPublishers.noBody())
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
