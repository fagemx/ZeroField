按指令用 AI 改写该集剧本正文，异步任务。

请求参数说明

Headers
参数	类型	必填	说明
Idempotency-Key	string	否	
幂等键。
Path 参数
参数	类型	必填	说明
episodeId	string	是	
对外剧集号。
示例：ep_4Rt7QxNp1
Body 参数
参数	类型	必填	说明
instruction	string	是	
改写指令，如“把第二场的雨夜氛围写得更压抑”。

forceRefresh	boolean	否	
强制重跑，绕过 LLM 幂等缓存；默认 false。
响应字段说明
参数	类型	必填	说明
taskId	string	是	
任务号。

type	string	是	
固定为 SCRIPT_REFINE。

result	object	否	
SUCCEEDED 后内容以内部润色接口的实际返回为准（一般含改写后的剧本快照信息）；具体字段未强类型约定，建议成功后另外调用 GET /episodes/(episodeId)/script/versions 拿最新快照。

注意

计费：按任务内模型调用的实际费用（网关标价，不加价）在任务终态一次性结算——成功扣款，失败不扣，取消按已消耗量扣（含取消时仍在进行的调用，账单在任务实际停止后结算）；金额按分四舍五入；模型由平台统一配置，不可指定。提交时余额需大于 0（团队 Key 看团队钱包，非团队 Key 看企业账户余额），否则返回 402 DRAMA_BALANCE_INSUFFICIENT；结算可能把余额扣成负数，之后的计费任务会被拦截直到充值。结算时若因系统原因扣款失败，账单记为欠费（ARREARS / ARREARS_PARTIAL_CANCELED），由平台自动补扣，不影响继续提交。任务从提交到终态占用一个企业 Key 并发名额（GET /quota 的 concurrentLimit），已满返回 429 DRAMA_CONCURRENCY_LIMIT，稍后重试。可用 GET /bills 查账单。

import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        String json = """
            {
              "instruction": "把第二场的雨夜氛围写得更压抑"
            }
            """;

        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/episodes/ep_4Rt7QxNp1/script-refinements"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .header("Idempotency-Key", "req-20260916-0001")
            .method("POST", HttpRequest.BodyPublishers.ofString(json))
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
