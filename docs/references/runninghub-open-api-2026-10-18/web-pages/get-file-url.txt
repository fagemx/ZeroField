GET
/files/{fileId}/url
复制
重新获取文件地址

为过期的文件重新生成签名访问地址。

请求参数说明

Path 参数
参数	类型	必填	说明
fileId	string	是	
成片文件号（fl_ 前缀，来自 GET /episodes/{id}/films 等成片接口）；上传文件 up_ 不适用，传入返回 404。
示例：fl_8Xr2Vb9
响应字段说明
参数	类型	必填	说明
fileId	string	是	
对外文件号。

url	string	是	
重新签名后的可访问地址。

expiresAt	string	是	
ISO-8601 过期时间，默认 24 小时后。

注意

仅适用成片文件号（fl_ 前缀，来自 GET /episodes/{id}/films 等成片接口）；上传文件 up_ 不适用，传入返回 404。
文件尚未生成完成（如导出仍在进行）时返回 409 DRAMA_FILE_NOT_READY。

请求示例

cURL
Python
JavaScript
Java
java
复制
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/files/fl_8Xr2Vb9/url"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .method("GET", HttpRequest.BodyPublishers.noBody())
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
