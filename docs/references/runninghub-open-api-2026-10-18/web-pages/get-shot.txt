查询镜头详情

按镜头号查询详情，字段同「镜头列表」。

请求参数说明

Path 参数
参数	类型	必填	说明
shotId	string	是	
对外镜头号。
示例：sh_7Qz3Rk9
响应字段说明
参数	类型	必填	说明
shotId	string	是	
对外镜头号。

sceneId	string	是	
所属场次号。

shotIndex	integer	是	
镜头在场次内的序号（1 起，按顺序连续）。

sceneIndex	integer	否	
所属场次的顺序号。

description	string	否	
画面描述纯文本。

dialogue	string	否	
台词纯文本，多段以换行分隔。

durationSeconds	integer	否	
镜头时长（秒）。

selectedImageUrl	string	否	
当前选中故事板图的可访问地址；未生成或未选中为 null。

selectedVideoUrl	string	否	
当前选中镜头视频的可访问地址；未生成或未选中为 null。

status	string	是	
优先级：选中的镜头视频状态 > 选中的故事板图状态 > PENDING。

注意

不属于当前企业 Key 或 id 不合法都返回 404 DRAMA_NOT_FOUND。

请求示例

cURL
Python
JavaScript
Java
java
复制
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/shots/sh_7Qz3Rk9"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .method("GET", HttpRequest.BodyPublishers.noBody())
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
