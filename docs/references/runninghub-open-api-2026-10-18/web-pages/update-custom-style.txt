PATCH
/styles/custom/{styleId}
复制
更新自定义画风

只更新非空字段。

请求参数说明

Path 参数
参数	类型	必填	说明
styleId	string	是	
对外自定义画风号。
示例：st_7Gy5Tb3
Body 参数
参数	类型	必填	说明
label	string	否	
画风名称。

prompt	string	否	
画风提示词。

coverUrl	string	否	
封面图地址。
响应字段说明
参数	类型	必填	说明
styleId	string	是	
对外自定义画风号。

label	string	是	
画风名称。

prompt	string	是	
画风提示词。

coverUrl	string	是	
封面图地址。

注意

不属于当前调用方或不存在都返回 404 DRAMA_NOT_FOUND。

请求示例

cURL
Python
JavaScript
Java
java
复制
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        String json = """
            {
              "label": "赛博水彩 v2"
            }
            """;

        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/styles/custom/st_7Gy5Tb3"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .method("PATCH", HttpRequest.BodyPublishers.ofString(json))
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
