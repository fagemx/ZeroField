PUT
/episodes/{episodeId}/script
复制
更新剧本

更新该集的剧本文本，落一份新快照。

请求参数说明

Path 参数
参数	类型	必填	说明
episodeId	string	是	
对外剧集号。
示例：ep_4Rt7QxNp1
Body 参数
参数	类型	必填	说明
scriptContent	string	是	
剧本文本内容。

scriptFileName	string	否	
剧本文件名，项目级字段，传了才会更新。
响应字段说明
参数	类型	必填	说明
episodeId	string	是	
对外剧集号。

projectId	string	是	
所属项目号。

title	string	是	
剧集标题。

episodeIndex	integer	是	
集数序号。

status	string	是	
剧集状态。
可选值： DRAFTCOMPLETED

stylePresetId	string	否	
画风预设 id（GET /catalog/styles），由 asset-extractions 时传入的值写入；尚未提取资产时为 null。

createdAt	string	是	
ISO-8601 创建时间。

注意

本接口不支持 Idempotency-Key（不是新建资源的操作）；内容与最新快照相同时直接复用、不新增版本。存入前会去掉 markdown 标题前缀，存入内容可能与提交文本略有差异。
保存剧本不触发任何模型调用、不计费。
发起 asset-extractions 之前必须先调用本接口至少一次，否则返回 422 DRAMA_STAGE_INPUT_EMPTY。

请求示例

cURL
Python
JavaScript
Java
java
复制
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        String json = """
            {
              "scriptContent": "第一集\n场景一：雨夜街头……（修订版）",
              "scriptFileName": "ep01_v2.txt"
            }
            """;

        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/episodes/ep_4Rt7QxNp1/script"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .method("PUT", HttpRequest.BodyPublishers.ofString(json))
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
