POST
/shots/{shotId}/image-generations
复制
镜头生图

为指定镜头生成故事板图，异步任务。

请求参数说明

Headers
参数	类型	必填	说明
Idempotency-Key	string	否	
幂等键。
Path 参数
参数	类型	必填	说明
shotId	string	是	
对外镜头号。
示例：sh_7Qz3Rk9
Body 参数
参数	类型	必填	说明
appCode	string	是	
生图应用码，取自 GET /catalog/apps（capability=IMAGE）。分镜生图只接受 I2I 应用：NANO_PRO_G2_I2I_OFFICIAL、NANO_PRO_G2_I2I_LOW、NANO_PRO_I2I_OFFICIAL、NANO_PRO_I2I_LOW、NANO_V2_I2I_OFFICIAL、NANO_V2_I2I_LOW，传其它应用返回 400 DRAMA_REQUEST_FAILED。appCode 区分大小写。
示例：NANO_PRO_G2_I2I_OFFICIAL

prompt	string	否	
自定义提示词；不传则用后端默认拼装逻辑。

aspectRatio	string	否	
画幅比例，如 16:9；不受支持时回落默认档。

resolution	string	否	
分辨率；不受支持时回落默认档。
响应字段说明
参数	类型	必填	说明
taskId	string	是	
任务号。

type	string	是	
固定为 SHOT_IMAGE_GENERATE。

result	object	否	
SUCCEEDED 后为 { imageUrl }。

注意

前置条件：镜头关联的角色 / 场景 / 道具至少要有一张资产图（先调用 POST /assets/{assetId}/image-generations），否则返回 409 DRAMA_STAGE_PRECONDITION。
新生成的图会自动成为当前选中（提交时即选中），体现为 GET /episodes/{episodeId}/shots 的 selectedImageUrl；PUT /shots/{shotId}/selected-image 用于在多个候选图间切换。

请求示例

cURL
Python

Java
java
复制
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        String json = """
            {
              "appCode": "NANO_PRO_G2_I2I_OFFICIAL",
              "aspectRatio": "16:9"
            }
            """;

        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/shots/sh_7Qz3Rk9/image-generations"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .header("Idempotency-Key", "req-20260916-0001")
            .method("POST", HttpRequest.BodyPublishers.ofString(json))
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
