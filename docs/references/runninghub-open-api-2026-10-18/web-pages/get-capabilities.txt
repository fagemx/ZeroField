GET
/capabilities
复制
能力清单

查询当前企业 Key 可用的阶段与功能开关。

响应字段说明
参数	类型	必填	说明
version	string	是	
接口版本号，当前恒为 v1。

site	enum	是	
当前企业 Key 归属的部署站点：CN 国内站（runninghub.cn），AI 海外站（runninghub.ai）。
可选值： CNAI

baseUrl	string	是	
当前站点的 Base URL（含 basePath），与“开始使用”页展示的一致。

stages	string[]	是	
可用阶段清单，一期为写死值，不代表某个项目的当前实际进度（进度请查 GET /episodes/{episodeId}）。

rateLimit	object	是	
当前企业 Key 的令牌桶限流参数，与 GET /quota 返回的 rateLimit 一致。

rateLimit.replenishRatePerSecond	integer	是	
每秒补充的令牌数。

rateLimit.burstCapacity	integer	是	
令牌桶容量，即突发请求上限。

features	object	是	
按部署实例固定的功能开关，同一站点所有企业 Key 看到的值相同（不按 Key 灰度）。

features.files	boolean	是	
是否开放文件上传（POST /files 等）。

features.projectImport	boolean	是	
是否开放一键导入（project-imports / project-generations）。

features.scriptTools	boolean	是	
是否开放剧本相关工具（AI 润色 / 快照 / 类型检测）。

features.editing	boolean	是	
是否开放分场 / 分镜编辑接口。

features.assetEditing	boolean	是	
是否开放资产改图与变体管理。

features.batchGeneration	boolean	是	
是否开放批量镜头生图 / 生视频。

features.taskRetry	boolean	是	
是否开放任务重试（POST /tasks/{taskNo}/retries）。

features.webhookDeliveries	boolean	是	
是否开放投递记录查询与手动重投。

features.usage	boolean	是	
是否开放用量 / 余额 / 配额查询。

features.sandbox	boolean	是	
是否处于沙箱模式，当前恒为 false，预留字段。

请求示例

Java
java
复制
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/capabilities"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .method("GET", HttpRequest.BodyPublishers.noBody())
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
