PATCH
/scenes/{sceneId}
复制
更新场次

修改场次标题 / 正文，字段为空不修改。

请求参数说明

Path 参数
参数	类型	必填	说明
sceneId	string	是	
对外场次号。
示例：sc_6Ym2Wq9
Body 参数
参数	类型	必填	说明
title	string	否	
新标题，不传则不改。

content	string	否	
新正文，不传则不改。
响应字段说明
参数	类型	必填	说明
sceneId	string	是	
对外场次号。

sceneIndex	integer	是	
场次序号。

title	string	否	
场次标题。

summary	string	否	
场次摘要。

status	string	是	
分镜生成状态。
可选值： IDLEGENERATINGDONEFAILED

content	string	是	
场次正文。

注意

改动正文不会自动重建下游镜头，已有分镜仍保留原样；需要刷新请另外调用 POST /scenes/(sceneId)/shot-rebuilds。

请求示例

cURL
Python
JavaScript
Java
java
复制
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        String json = """
            {
              "content": "雨夜，林夏疾步奔跑在空无一人的街道上……（改写版）"
            }
            """;

        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/scenes/sc_6Ym2Wq9"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .method("PATCH", HttpRequest.BodyPublishers.ofString(json))
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
