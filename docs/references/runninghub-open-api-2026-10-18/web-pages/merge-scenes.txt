POST
/scene-merges
复制
合并场次

把两个场次合并为一个（第二个合入第一个）。

请求参数说明

Body 参数
参数	类型	必填	说明
sceneIds	string[]	是	
必须正好传 2 个场次号（数量不为 2 返回 422 DRAMA_VALIDATION_FAILED），第 2 个合入第 1 个；第 2 个场次会被软删。
响应字段说明
参数	类型	必填	说明
sceneId	string	是	
合并后仍存在的场次号（即传入的第 1 个）。

sceneIndex	integer	是	
场次序号。

title	string	否	
场次标题。

summary	string	否	
场次摘要。

status	string	是	
分镜生成状态。
可选值： IDLEGENERATINGDONEFAILED

content	string	是	
合并后的正文。

注意

sceneIds 数量不为 2，或任一 id 不合法 / 不属于当前 Key，分别返回 422 DRAMA_VALIDATION_FAILED / 404 DRAMA_NOT_FOUND。

请求示例

cURL
Python
JavaScript
Java
java
复制
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        String json = """
            {
              "sceneIds": [
                "sc_6Ym2Wq9",
                "sc_8Pr4Ty6"
              ]
            }
            """;

        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/scene-merges"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .method("POST", HttpRequest.BodyPublishers.ofString(json))
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
