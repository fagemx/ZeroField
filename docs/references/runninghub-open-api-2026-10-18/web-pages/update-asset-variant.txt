PATCH
/assets/{assetId}/variants/{variantId}
复制
更新变体

修改变体名称 / 描述文案，字段为空不修改。

请求参数说明

Path 参数
参数	类型	必填	说明
assetId	string	是	
对外资产号。
示例：as_5Ln9Vt2

variantId	string	是	
变体号。
示例：vr_7Nq4Su2
Body 参数
参数	类型	必填	说明
name	string	否	
新名称，不传则不改。

prompt	string	否	
新描述文案，不传则不改。
响应字段说明
参数	类型	必填	说明
variantId	string	是	
变体号。

kind	enum	否	
变体种类。
可选值： OUTFITPOSELOOK

name	string	是	
变体名称。

description	string	否	
变体描述文案。

imageUrl	string	否	
当前展示图地址。

isDefault	boolean	否	
是否为默认变体。

sortOrder	integer	否	
排序序号。

请求示例

cURL
Python
JavaScript
Java
java
复制
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        String json = """
            {
              "prompt": "深色雨衣，湿发，手持雨伞"
            }
            """;

        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/assets/as_5Ln9Vt2/variants/vr_7Nq4Su2"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .method("PATCH", HttpRequest.BodyPublishers.ofString(json))
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
