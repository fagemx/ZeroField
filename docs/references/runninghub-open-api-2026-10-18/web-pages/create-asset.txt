创建资产

在指定剧集下手动创建一个资产（角色 / 场景 / 道具）。

请求参数说明

Path 参数
参数	类型	必填	说明
episodeId	string	是	
对外剧集号。
示例：ep_4Rt7QxNp1
Body 参数
参数	类型	必填	说明
name	string	是	
资产名称。
示例：林夏

type	enum	是	
资产类型；非法值返回 422。
可选值： CHARACTERSCENEPROP

description	string	否	
资产描述，可空。
响应字段说明
参数	类型	必填	说明
assetId	string	是	
对外资产号。

name	string	是	
资产名称。

type	enum	是	
资产类型。
可选值： CHARACTERSCENEPROP

description	string	否	
资产描述。

imageUrl	string	否	
刚创建时没有任何变体图片，恒为 null。

createdAt	string	是	
ISO-8601 创建时间。

注意

不支持 Idempotency-Key，重复提交会创建多个同名资产。

请求示例

cURL
Python
JavaScript
Java
java
复制
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        String json = """
            {
              "name": "林夏",
              "type": "CHARACTER",
              "description": "女主角，25岁，短发"
            }
            """;

        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/episodes/ep_4Rt7QxNp1/assets"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .method("POST", HttpRequest.BodyPublishers.ofString(json))
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
