创建项目

创建一个新项目，可同时传入剧本文本。

请求参数说明

Headers
参数	类型	必填	说明
Idempotency-Key	string	否	
幂等键，按（企业 Key，该值）24 小时内去重；同 key 请求体不同返回 409。
示例：create-project-20260916-0001
Body 参数
参数	类型	必填	说明
title	string	是	
项目标题。
示例：霓虹都市

description	string	否	
项目简介。

scriptContent	string	否	
剧本文本内容，可与 scriptFileName 同时提供。只存在项目上，不会写入任何剧集的剧本：要走提资产 / 分镜，仍需对每集调用 PUT /episodes/{episodeId}/script 写入剧本（或改用 POST /project-imports 自动分集）。

scriptFileName	string	否	
上传的剧本文件名，仅作展示用途。
响应字段说明
参数	类型	必填	说明
projectId	string	是	
对外项目号，pj_ 前缀。

title	string	是	
项目标题。

description	string	否	
项目简介。

status	string	是	
项目状态，新建时固定为 DRAFT。

createdAt	string	是	
ISO-8601 创建时间。

updatedAt	string	是	
ISO-8601 最近更新时间。

注意

通过本接口创建的项目会打上来源标记（source=OPEN_API），在网页端工作台同样可见。

请求示例

cURL

Java
java
复制
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        String json = """
            {
              "title": "霓虹都市",
              "description": "赛博朋克短剧",
              "scriptContent": "第一集\n场景一：雨夜街头……",
              "scriptFileName": "ep01.txt"
            }
            """;

        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/projects"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .header("Idempotency-Key", "create-project-20260916-0001")
            .method("POST", HttpRequest.BodyPublishers.ofString(json))
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
