GET
/episodes/{episodeId}/films
复制
成片列表

查询该集全部成片记录（不分页）。

请求参数说明

Path 参数
参数	类型	必填	说明
episodeId	string	是	
对外剧集号。
示例：ep_4Rt7QxNp1
响应字段说明
参数	类型	必填	说明
fileId	string	是	
对外文件号，fl_ 前缀。

status	enum	是	
导出状态。
可选值： EXPORTINGEXPORTEDFAILED

videoUrl	string	否	
仅 status=EXPORTED 时非空，24 小时签名地址；过期后用 GET /files/{fileId}/url 重新获取。

createdAt	string	是	
ISO-8601 创建时间。

请求示例

cURL
Python
JavaScript
Java
java
复制
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/episodes/ep_4Rt7QxNp1/films"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .method("GET", HttpRequest.BodyPublishers.noBody())
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
