GET
/usage
复制
用量查询

按天或按阶段汇总 LLM 阶段账单用量。

请求参数说明

Query 参数
参数	类型	必填	说明
from	string	否	
起始日期（含），格式 YYYY-MM-DD；不传按 to 往前推 29 天。
示例：2026-08-19

to	string	否	
结束日期（含），格式 YYYY-MM-DD；不传按今天。
示例：2026-09-17

groupBy	enum	否	
分组维度；不传按 day，不是 day / stage 返回 422 DRAMA_VALIDATION_FAILED。
可选值： daystage
响应字段说明
参数	类型	必填	说明
from	string	是	
回显的起始日期。

to	string	是	
回显的结束日期。

groupBy	string	是	
回显的分组维度。

items	object[]	是	
按 groupBy 分组的明细：groupBy=day 时 key 是 YYYY-MM-DD 日期字符串，groupBy=stage 时 key 是计费任务类型（ASSET_EXTRACT / STORYBOARD_GENERATE / SHOTS_REBUILD / PROJECT_IMPORT / PROJECT_GENERATE / SCRIPT_REFINE / SCENE_REFINE / PROJECT_REEXTRACT，与 GET /bills 的 stage 一致）。

items[].key	string	是	
分组键，见上。

items[].taskCount	string	是	
该分组内的账单行数（近似任务数）；64 位整数以数字字符串返回。

items[].inputTokens	string	是	
输入 token 总数；64 位整数以数字字符串返回。

items[].outputTokens	string	是	
输出 token 总数；64 位整数以数字字符串返回。

items[].amount	number	是	
实付金额合计。

items[].currency	string	否	
币种；该分组无任何行时为 null。

total	object	是	
整个查询区间的汇总行，字段结构同 items 元素，key 恒为 null。

注意

只统计状态为 CHARGED / CHARGED_PARTIAL_CANCELED 的 LLM 计费账单（同 GET /bills 的数据源），欠费账单（ARREARS / ARREARS_PARTIAL_CANCELED）补扣成功前不计入；生图 / 生视频计费不在这里体现。
from 晚于 to、查询跨度超过 92 天、日期格式非法，或 groupBy 不是 day / stage，均返回 422 DRAMA_VALIDATION_FAILED。

请求示例

cURL
Python
JavaScript
Java
java
复制
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/usage?from=2026-08-19&to=2026-09-17&groupBy=%3CgroupBy%3E"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .method("GET", HttpRequest.BodyPublishers.noBody())
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
