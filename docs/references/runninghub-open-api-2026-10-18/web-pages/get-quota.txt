GET
/quota
复制
配额查询

查询当前企业 Key 的消费配额、并发上限与限流参数。

响应字段说明
参数	类型	必填	说明
quotaLimit	number	否	
配额上限；为 null 表示不限额。

quotaUsed	number	是	
已消费配额。

quotaRemaining	number	否	
剩余配额；quotaLimit 为 null（不限额）时本字段同为 null。

currency	string	是	
币种，国内站 CNY、海外站 USD。

concurrentLimit	integer	是	
LLM 计费任务（提资产 / 分镜 / 单场重建 / 导入 / 生成 / 润色 / 场次改写 / 重提取）的并发上限，对应企业 Key 配置，超出返回 429 DRAMA_CONCURRENCY_LIMIT；生图 / 生视频 / 导出不占用。

rateLimit	object	是	
令牌桶限流参数，与 GET /capabilities 返回的 rateLimit 一致。

rateLimit.replenishRatePerSecond	integer	是	
每秒补充的令牌数。

rateLimit.burstCapacity	integer	是	
令牌桶容量，即突发请求上限。

注意

quotaLimit 为 null 的企业 Key 不受配额门禁限制，但仍受 concurrentLimit 与 rateLimit 约束。

Java
java
复制
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/quota"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .method("GET", HttpRequest.BodyPublishers.noBody())
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
