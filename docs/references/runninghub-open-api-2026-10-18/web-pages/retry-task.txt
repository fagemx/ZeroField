POST
/tasks/{taskNo}/retries
复制
重试任务

用原始请求重新提交一次，产生一个全新任务；不影响原任务的状态。

请求参数说明

Path 参数
参数	类型	必填	说明
taskNo	string	是	
要重试的对外任务号。
示例：tk_9As7Qt4
响应字段说明
参数	类型	必填	说明
taskId	string	是	
新任务号，与传入的 taskNo 不同。

type	string	是	
与原任务相同的任务类型。

status	string	是	
提交时固定为 QUEUED。

注意

仅 SHOT_IMAGE_GENERATE / SHOT_VIDEO_GENERATE / ASSET_IMAGE_GENERATE 三种任务类型支持重试（只有这三类落库时记录了原始请求），且原任务须已是 FAILED / CANCELED；其余类型，或原任务仍在 QUEUED / RUNNING、已 SUCCEEDED，均返回 409 DRAMA_OPERATION_NOT_ALLOWED。
不支持 Idempotency-Key，每次调用都会产生一个全新任务，不做去重；原任务保留在 GET /tasks 里不变（不会被覆盖或删除）。
按原始请求重新校验一遍前置条件（如资产是否有默认变体、appCode 是否仍可用），原来能提交不代表这次重试一定能成功。

Java
java
复制
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/tasks/tk_9As7Qt4/retries"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .method("POST", HttpRequest.BodyPublishers.noBody())
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
