场次重新排序

按给定顺序重排该集的场次。

请求参数说明

Path 参数
参数	类型	必填	说明
episodeId	string	是	
对外剧集号。
示例：ep_4Rt7QxNp1
Body 参数
参数	类型	必填	说明
sceneIds	string[]	是	
按目标顺序排列的场次号列表，最多 200 项（超出返回 422）；建议一次性传入该集全部未删场次的 id，未包含在列表里的场次相对顺序由内部实现决定，不保证符合预期。

注意

sceneIds 中任意一个不属于路径里的 episodeId 都会返回 404 DRAMA_NOT_FOUND，整批不生效。

请求示例

cURL
Python
JavaScript
Java
java
复制
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        String json = """
            {
              "sceneIds": [
                "sc_8Pr4Ty6",
                "sc_6Ym2Wq9"
              ]
            }
            """;

        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/episodes/ep_4Rt7QxNp1/scene-order"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .method("PUT", HttpRequest.BodyPublishers.ofString(json))
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
