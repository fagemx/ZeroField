/shots
复制
批量更新镜头

一次提交多条镜头的字段更新，逐条应用；任一条 shotId 非法则整个请求以 422 / 404 终止，不做部分成功。

请求参数说明

Body 参数
参数	类型	必填	说明
items	object[]	是	
待更新镜头列表，最多 200 项（超出返回 422）；每项字段同「更新镜头」的请求体（外加必填的 shotId）。

items[].shotId	string	是	
对外镜头号。

items[].description	string	否	
新画面描述，不传则不改。

items[].dialogue	string	否	
新台词，不传则不改。

items[].durationSeconds	integer	否	
新镜头时长（秒），不传则不改。1~600 秒整数，越界返回 422。
响应字段说明
参数	类型	必填	说明
(array item)	object	是	
更新后的镜头列表，按请求 items 顺序返回，字段结构同「查询镜头详情」。

注意

本接口是逐条串行调用「更新镜头」的等价封装，不是原子事务；某一项 shotId 不合法会导致整个请求报错终止（不是跳过），请确保 items 里每个 shotId 都合法且属于当前 Key。

import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        String json = """
            {
              "items": [
                {
                  "shotId": "sh_7Qz3Rk9",
                  "durationSeconds": 4
                },
                {
                  "shotId": "sh_2Uw6Xy4",
                  "dialogue": "（无台词）"
                }
              ]
            }
            """;

        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/shots"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .method("PATCH", HttpRequest.BodyPublishers.ofString(json))
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
