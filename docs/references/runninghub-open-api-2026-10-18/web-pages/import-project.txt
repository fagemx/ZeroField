导入剧本建项目

用已有剧本一次性建项目、自动分集、规整剧本，异步任务。只做剧本规整 + 自动分集 + 建项目，不会拆分场次、不会提取资产。

请求参数说明

Headers
参数	类型	必填	说明
Idempotency-Key	string	否	
幂等键，按（企业 Key，该值）24 小时内去重。
Body 参数
参数	类型	必填	说明
scriptFileId	string	否	
剧本文件号（up_ 前缀），来自 POST /files 且 purpose=SCRIPT；与 scriptContent 二选一。
示例：up_3Fq8Nx2

scriptContent	string	否	
剧本文本内容；与 scriptFileId 二选一。

scriptFileName	string	否	
剧本文件名，仅展示用途；传 scriptFileId 时缺省取该文件的原始文件名。

aspectRatio	enum	否	
画幅，写入自动创建的每一集的取向；不传则不设置（沿用系统默认）。
可选值： 16:99:16

contentLanguage	string	否	
当前只接收、不生效，内部流水线暂无对应的语言覆盖入口，见下方备注。

stylePresetId	string	否	
画风预设 id，取自 GET /catalog/styles 的 stylePresetId（不是自定义画风的 st_ 前缀 id），写入每一集；非数字字符串返回 422 DRAMA_STYLE_NOT_FOUND（提交时不校验该 id 是否真实存在）。

title	string	否	
项目标题覆盖；不传则按剧本内容自动生成。
响应字段说明
参数	类型	必填	说明
taskId	string	是	
任务号。

type	string	是	
固定为 PROJECT_IMPORT。

result	object	否	
SUCCEEDED 后为 projectId、episodeId、episodeCount 三个字段：projectId 是新建项目的对外 id（pj_ 前缀），episodeId 是拆出的第一集的对外 id（ep_ 前缀），可直接用于 GET /projects/(projectId)、GET /episodes/(episodeId) 等后续调用；episodeCount 是本次实际创建的剧集数；episodes 是本次创建的全部剧集数组，每项为 {episodeId, episodeIndex, title}，episodeIndex 从 1 起，例：[{"episodeId":"ep_4Rt7QxNp1","episodeIndex":1,"title":"第一集"}]。

注意

scriptFileId 与 scriptContent 必须二选一，都传或都不传返回 400 DRAMA_REQUEST_FAILED；scriptContent 为空白或 scriptFileId 指向的文件不是已成功解析出文本的 purpose=SCRIPT 文件，返回 422 DRAMA_SCRIPT_INVALID；剧本字数超出平台单次上限返回 400 DRAMA_REQUEST_FAILED。
一次调用可能按内容拆出多集，episodeId 只给第一集，全部剧集见 result.episodes（也可用 GET /projects/(projectId)/episodes 翻页获取）。result 里不再包含网页端专用字段。
导入只做剧本规整 + 自动分集 + 建项目，不会拆分场次、不会提取资产。任务内还会提取标题、生成项目简介 / 人物介绍 / 各集概述，并把概述与人物介绍前置到第一集剧本开头；这些模型调用都计入本任务账单。任务 SUCCEEDED 后，取 result.episodes 中任意一集调用一次 POST /episodes/{episodeId}/asset-extractions 即可：首次提取为项目级，对整本剧本一次完成场次拆分与资产提取、覆盖全部剧集（与网页端「确认剧本」一致），之后才能生成分镜；按 ASSET_EXTRACT 单独计费。
aspectRatio / stylePresetId 会实际写入自动创建的每一集；contentLanguage 目前只接收不生效（内部快速生成流程没有对应的语言覆盖参数）。
通过本接口创建的项目同样打上 source=OPEN_API 标记，在网页端工作台可见。
计费：按任务内模型调用的实际费用（网关标价，不加价）在任务终态一次性结算——成功扣款，失败不扣，取消按已消耗量扣（含取消时仍在进行的调用，账单在任务实际停止后结算）；金额按分四舍五入；模型由平台统一配置，不可指定。提交时余额需大于 0（团队 Key 看团队钱包，非团队 Key 看企业账户余额），否则返回 402 DRAMA_BALANCE_INSUFFICIENT；结算可能把余额扣成负数，之后的计费任务会被拦截直到充值。结算时若因系统原因扣款失败，账单记为欠费（ARREARS / ARREARS_PARTIAL_CANCELED），由平台自动补扣，不影响继续提交。任务从提交到终态占用一个企业 Key 并发名额（GET /quota 的 concurrentLimit），已满返回 429 DRAMA_CONCURRENCY_LIMIT，稍后重试。可用 GET /bills 查账单。

import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        String json = """
            {
              "scriptFileId": "up_3Fq8Nx2",
              "aspectRatio": "16:9",
              "stylePresetId": "88123",
              "title": "霓虹都市"
            }
            """;

        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/project-imports"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .header("Idempotency-Key", "req-20260916-0001")
            .method("POST", HttpRequest.BodyPublishers.ofString(json))
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
