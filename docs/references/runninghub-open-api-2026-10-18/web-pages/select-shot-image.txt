PUT
/shots/{shotId}/selected-image
复制
选定镜头图

把某张候选图设为该镜头的当前选中图。

请求参数说明

Path 参数
参数	类型	必填	说明
shotId	string	是	
对外镜头号。
示例：sh_7Qz3Rk9
Body 参数
参数	类型	必填	说明
imageId	string	是	
候选图 id（im_ 前缀），取自 GET /shots/{shotId}/images。
示例：im_9Pq2Kd

注意

本接口不支持 Idempotency-Key；重复调用同一 imageId 是幂等的（结果不变）。
imageId 不属于路径里的镜头时返回 404 DRAMA_NOT_FOUND。

请求示例

cURL
Python
JavaScript
Java
java
复制
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        String json = """
            {
              "imageId": "im_9Pq2Kd"
            }
            """;

        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/shots/sh_7Qz3Rk9/selected-image"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .method("PUT", HttpRequest.BodyPublishers.ofString(json))
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
