/scenes/{sceneId}/shots

创建镜头

在指定场次下手动插入一个镜头。

请求参数说明

Path 参数
参数	类型	必填	说明
sceneId	string	是	
对外场次号。
示例：sc_6Ym2Wq9
Body 参数
参数	类型	必填	说明
description	string	是	
画面描述。
示例：林夏推开便利店的门，风铃作响。

dialogue	string	否	
台词，可空。

durationSeconds	integer	否	
镜头时长（秒），可空。1~600 秒整数，越界返回 422。

afterShotId	string	否	
插入锚点：新镜头紧跟该镜头之后（须同场次）；不传则追加到场次末尾。
响应字段说明
参数	类型	必填	说明
shotId	string	是	
对外镜头号。

sceneId	string	是	
所属场次号。

shotIndex	integer	是	
镜头在场次内的序号（1 起，按顺序连续）。

sceneIndex	integer	否	
所属场次的顺序号。

description	string	否	
画面描述。

dialogue	string	否	
台词。

durationSeconds	integer	否	
镜头时长（秒）。

selectedImageUrl	string	否	
新建时恒为 null。

selectedVideoUrl	string	否	
新建时恒为 null。

status	string	是	
新建时恒为 PENDING。

注意

afterShotId 不属于同一场次时返回 404 DRAMA_NOT_FOUND。
不支持 Idempotency-Key，重复提交会创建多个镜头。

请求示例

cURL
Python

Java
java
复制
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        String json = """
            {
              "description": "林夏推开便利店的门，风铃作响。",
              "durationSeconds": 3
            }
            """;

        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/scenes/sc_6Ym2Wq9/shots"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .method("POST", HttpRequest.BodyPublishers.ofString(json))
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
