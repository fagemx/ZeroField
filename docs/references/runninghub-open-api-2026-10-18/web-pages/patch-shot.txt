PATCH
/shots/{shotId}
复制
更新镜头

修改镜头的画面描述 / 台词 / 时长，字段为空不修改。

请求参数说明

Path 参数
参数	类型	必填	说明
shotId	string	是	
对外镜头号。
示例：sh_7Qz3Rk9
Body 参数
参数	类型	必填	说明
description	string	否	
新画面描述，不传则不改。

dialogue	string	否	
新台词，不传则不改。

durationSeconds	integer	否	
新镜头时长（秒），不传则不改。1~600 秒整数，越界返回 422。
响应字段说明
参数	类型	必填	说明
(object)	object	是	
更新后的镜头，字段结构同「查询镜头详情」（shotId / sceneId / shotIndex / sceneIndex / description / dialogue / durationSeconds / selectedImageUrl / selectedVideoUrl / status）。

请求示例

cURL
Python
JavaScript
Java
java
复制
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        String json = """
            {
              "durationSeconds": 6
            }
            """;

        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/shots/sh_7Qz3Rk9"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .method("PATCH", HttpRequest.BodyPublishers.ofString(json))
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
