POST
/assets/{assetId}/variants
复制
创建变体

为资产新增一个服饰 / 表情 / 姿势变体。

请求参数说明

Path 参数
参数	类型	必填	说明
assetId	string	是	
对外资产号。
示例：as_5Ln9Vt2
Body 参数
参数	类型	必填	说明
name	string	是	
变体名称。
示例：雨夜装

prompt	string	否	
变体描述文案，可空。

kind	enum	否	
变体种类，不传由后端按资产类型决定；非法值返回 422 DRAMA_VALIDATION_FAILED。
可选值： OUTFITPOSELOOK
响应字段说明
参数	类型	必填	说明
variantId	string	是	
变体号。

kind	enum	否	
变体种类。
可选值： OUTFITPOSELOOK

name	string	是	
变体名称。

description	string	否	
变体描述文案。

imageUrl	string	否	
刚创建时未生图，恒为 null。

isDefault	boolean	否	
是否为默认变体，新建变体一般为 false。

sortOrder	integer	否	
排序序号。

请求示例

cURL
Python
JavaScript
Java
java
复制
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        String json = """
            {
              "name": "雨夜装",
              "prompt": "深色雨衣，湿发",
              "kind": "OUTFIT"
            }
            """;

        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/assets/as_5Ln9Vt2/variants"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .method("POST", HttpRequest.BodyPublishers.ofString(json))
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
