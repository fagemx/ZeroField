GET
/episodes/{episodeId}/scenes
复制
场次列表

查询该集全部场次（不分页）。

请求参数说明

Path 参数
参数	类型	必填	说明
episodeId	string	是	
对外剧集号。
示例：ep_4Rt7QxNp1
响应字段说明
参数	类型	必填	说明
sceneId	string	是	
对外场次号，sc_ 前缀。

sceneIndex	integer	是	
场次序号，从 1 开始。

title	string	否	
场次标题。

summary	string	否	
场次摘要。

status	string	是	
本场的分镜生成状态（不是场次综合状态），用于判断能否发起 shot-rebuilds：IDLE 未生成、GENERATING 生成中、DONE 已完成、FAILED 上次生成失败。
可选值： IDLEGENERATINGDONEFAILED

请求示例

cURL

Java
java
复制
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/episodes/ep_4Rt7QxNp1/scenes"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .method("GET", HttpRequest.BodyPublishers.noBody())
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
