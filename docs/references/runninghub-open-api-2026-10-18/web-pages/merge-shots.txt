/shot-merges
复制
合并镜头

把两个镜头合并为一个（第二个合入第一个）。

请求参数说明

Body 参数
参数	类型	必填	说明
shotIds	string[]	是	
必须正好传 2 个镜头号（数量不为 2 返回 422 DRAMA_VALIDATION_FAILED），第 2 个合入第 1 个；第 2 个镜头会被软删。
响应字段说明
参数	类型	必填	说明
shotId	string	是	
合并后仍存在的镜头号（即传入的第 1 个）。

(other fields)	object	是	
合并后的镜头，其余字段同「查询镜头详情」（sceneId / shotIndex / sceneIndex / description / dialogue / durationSeconds / selectedImageUrl / selectedVideoUrl / status）。

注意

shotIds 数量不为 2，或任一 id 不合法 / 不属于当前 Key，分别返回 422 DRAMA_VALIDATION_FAILED / 404 DRAMA_NOT_FOUND；合并会重置已生成的故事板图 / 视频关联。

请求示例

cURL
Python
JavaScript
Java
java
复制
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Example {
    static final String RH_API_KEY = "";

    public static void main(String[] args) throws Exception {
        String json = """
            {
              "shotIds": [
                "sh_7Qz3Rk9",
                "sh_2Uw6Xy4"
              ]
            }
            """;

        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://story.runninghub.ai/aivideo/open/v1/shot-merges"))
            .header("Authorization", "Bearer " + RH_API_KEY)
            .header("Content-Type", "application/json")
            .method("POST", HttpRequest.BodyPublishers.ofString(json))
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
