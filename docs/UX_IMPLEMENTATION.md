## 裁定

- 延續 `codex/productization` 現有未提交成果。新 worktree 不含大量未提交基礎，故使用本工作區，不搬移／清理原有成果、不提交推送。

- 普通編輯直接保存並可復原；代理提案人工核對。合成專案做可寫走查；不呼叫付費生成服務。

- 流程採 MIT `@xyflow/react` 12.12.0 核心，保留既有執行資料轉接，沒有複製 Pro 範例。Vite 升至 6.4.4，安裝審計為 0 個已報告弱點。

## 交付界線

- 本輪的瀏覽器證據為 1280×720。125% 瀏覽器縮放操作未生效，沒有列為通過；亦未做真實中文輸入法候選字組合的人工測試。程式有 composition 保護，但不以此代替輸入法實測。
- 匯入可選表頭列；多工作表目前一次指定一張的表頭，其他工作表預設第一列。完整 Excel 工作簿語意、所有公式、特殊物件及任意選區匯入不在已驗證能力中。
- 更新既有分頁是明示的整檔取代：核對目前內容與新檔（最多 50 筆差異，超過會標示）並勾選取代確認；不是自動三方合併。影響既有公式／流程時會拒絕並建議匯入新分頁。不能可靠辨識的列不硬接舊留言，保留為待重對位。
- 最新替換核對 UI 已完成前後端契約覆核與測試，但瀏覽器選檔工具逾時未返回，沒有列為完整瀏覽器走查通過；該次未按任何確認匯入／取代，專用 Chrome 分頁已關閉。先前建立新分頁的表頭選擇、200×20 匯入及 Excel 下載已另外實測。
- 欄位／列變動若影響公式或流程會保守阻擋，不自動改寫引用。儲存格有原子撤銷／重做；結構變更目前使用版本紀錄，未宣稱所有結構操作都有同一套快捷撤銷。
- 單步實際執行、來源過期、審核、取消、重試由本機測試 Worker 驗證；未呼叫真實付費模型。部署容器與外部 GPU／多供應商的本輪實測另列。
