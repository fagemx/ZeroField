# 表格與匯入實作走查（2026-10-16）

本紀錄是代理實作與合成資料測試證據，不代表使用者操作驗收。測試服務為 `127.0.0.1:3023`，專案 `ux-usability-1016`，未開啟模型 worker；沒有使用公司或真實個人資料。

## 已實作

- 格內輸入、雙擊／F2、Enter 儲存後往下、Tab 往右、Shift+Enter 換行、Escape 取消。中文 composition 期間不提交；尚未用實體輸入法驗證組字過程。
- 拖選／Shift 方向鍵、矩形 TSV 複製、依可見列 ID 貼上；多格貼上先看固定範圍，不把篩選結果轉成來源連續列。數字與狀態驗證失敗不部分寫入。
- 一次操作撤銷／重做使用逐格原值及欄 ID 條件；衝突保留草稿。明確選擇以最新原值重套才會重建原值條件，重試不會自動覆寫他人的值。
- 儲存與失敗狀態、目前／我的內容比較、重試。未儲存時阻擋分頁／文件模式切換、匯出與欄位結構操作。
- 緊湊工具列，欄位改名／型態／狀態選項及視圖排序／寬度／隱藏；後端檢查刪欄依賴。結構操作清空格級撤銷，保留版本紀錄，不宣稱支援結構撤銷。
- 按需列詳情，圖庫／看板共享列與狀態；中央寬版圖片審核、上一筆／下一筆、歷史媒體比較與留言；影片保留附件，不出現播放器。
- 代理需求固定來源版本、列及欄 ID。工作流來源跳轉使用指定工作表與列 ID，取消篩選並定位格；來源已刪除時顯示錯誤。
- 匯入前讀取預覽、指定表頭、選擇交付方式；多檔逐份確認。更新既有分頁提供整份取代差異、重複列對位提醒及明確勾選，才送出 `confirm_replace=true`。選項一改就取消勾選，舊預覽不能提交。

## 實際瀏覽器通過

1. 日報 C1 由 `12000` 改為 `12500`；Enter 成功寫回後焦點到 C2，公式由 `1.55` 變為 `1.488`。一次撤銷恢復 `12000` 及 `1.55`。
2. Shift+Left／Up 選取 B1:C2；剪貼簿為 `Meta\t12500\nGoogle\t8500`。貼上四格前顯示預覽，成功後可一次撤銷四格。
3. 新增合成第三列，搜尋 Meta 只顯示第一／第三列；貼上兩列明列原始第 1／3 列。寫回 C1=`12111`、C3=`4111`，隱藏的 C2 保持 `8500`，再撤銷恢復。新增測試列留在合成專案。
4. 欄名「渠道／項目」改成「渠道／來源」成功。嘗試刪除被公式依賴的「花費」欄被拒絕，錯誤顯示在確認面板，原表仍完整。
5. 使用 [200×20 CSV 合成檔](../../tests/fixtures/ux-office-200x20.csv)，原始前兩列為說明、第三列為表頭；在匯入預覽選第 3 列，確認後得到 200 列、20 欄。包含中文換行、逗號、日期及空格值。
6. 200×20 資料全選複製得到 28,259 字元，第一筆中文換行依 TSV 引號保留，末尾為 `內容 200-20`；可捲動／定位 T200。此為操作樣本，不是容量或效能上限。
7. 經介面「另存新工作簿」實際下載 Excel。驗證結果為 201 列（含表頭）×20 欄，A1 為日期，E2 保留中文換行，T201 為 `內容 200-20`。

瀏覽器選檔及下載工具有顯著額外等待，不能用工具整體耗時推論應用程式性能。最後一次下載工具耗時 971 秒才返回；未宣稱匯出花費相同時間。

## 自動化與尚待驗證

新增純函式測試先驗證失敗，再完成實作：篩選／排序貼上的列 ID、逐格 CAS、矩形複製、整次撤銷、固定代理範圍、型態驗證、明確衝突重套、選定表頭公式位移、匯入目標版本與確認標記。最後局部執行 16 項全部通過；整體 build 與其餘測試由主代理統一驗證。

尚待：原生中文 IME 組字、125% 顯示比例、長時間多人共同編輯、大於目前樣本的效能、真實素材逐筆審核，以及最新整份取代差異介面的獨立瀏覽器走查。純函式／後端測試與截圖各自提供證據，不互相替代。
